# Contributing EarthMeet

Please read [Code of Conduct](./CODE_OF_CONDUCT.md) before contributing to this repository.

## How You should Contribute

Welcome to our project! We welcome your contribution to our project.

### Step 1: Reading the Issues

Please read the [Issues](https://github.com/Tayra-Sakurai/EarthMeet/issues) before your contribution.

When you find an issue which you can fix, please fork this repository and make a new branch.

Please feel free to add new issue when you find a new issue which is not in [Issues](https://github.com/Tayra-Sakurai/EarthMeet/issues).

### Step 2: Beginning the edition.

Please make a new branch before you make changes on the repository.

### Step 3: Make a Pull Request

Please make your pull request with using the template.
